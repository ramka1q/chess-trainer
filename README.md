# ♞ Шаховий тренер

Тренер для гравців приблизно від 300 до 1500 ело: шлях з уроків (кожен треба пройти 3 рази поспіль без помилок), інтервальне повторення, задачі, бачення дошки, розрахунок, стратегія, дебюти, ендшпілі, партії майстрів, розбір власних партій із chess.com і lichess, контрольний тест раз на місяць.

## Як користуватися

**У браузері / на телефоні:** відкрий сайт (GitHub Pages). Рушій — Stockfish 17.1 прямо в браузері:
- «швидкий» (7 МБ) — за замовчуванням;
- «повний» (≈80 МБ, сильніший) — вибери в налаштуваннях «Хто думає».

На телефоні можна додати тренер на головний екран («Додати на головний екран» у меню браузера) — він відкриватиметься як застосунок, а рушій зберігається й не завантажується щоразу.

**На ПК (найсильніше):** завантаж `chess-trainer-pc.zip` зі сторінки Releases, розпакуй і двічі клікни `Запустити шахи.cmd`. Потрібен Python 3. Під час першого запуску тренер сам завантажить офіційний Stockfish 19 (≈80 МБ) і рахуватиме на всіх ядрах процесора.

Прогрес зберігається в браузері: не очищай дані сайту, інакше він зникне.

## Чесна гра

Тренер — для навчання **до і після** партій. Не відкривай його під час гри на chess.com чи lichess: це порушує правила чесної гри.

## Подяки та ліцензії

- [Stockfish](https://stockfishchess.org/) (GPLv3) — шаховий рушій; браузерна версія з пакета [stockfish.js](https://github.com/nmrugg/stockfish.js) (файл `stockfish-mt.js` — його незмінна копія для багатоядерного режиму).
- [chess.js](https://github.com/jhlywa/chess.js) (BSD-2) — правила шахів.
- Фігури «cburnett» — Colin M.L. Burnett, CC BY-SA 3.0 (як на lichess).
- Задачі та партії майстрів — відкрита база [lichess.org](https://lichess.org) (CC0).

Проєкт не пов’язаний з chess.com чи lichess.org.
